# FHIR-50738: Gender Identity resource in Data Model

**JIRA:** https://jira.hl7.org/browse/FHIR-50738
**Status:** Triaged | **Resolution:** None
**Ballot:** may-2025 | **Section:** Data Model
**Proposed Resolution:** Needs Workgroup Discussion

## Ballot Comment
The SPHR Data Model includes a FHIR Patient resource "Gender Identity" associated with the Gender Harmony project. FEHRM (Federal Electronic Health Record Modernization) registered a negative vote citing Executive Order 14168.

## Proposed Action
This is a sensitive policy matter requiring workgroup discussion. Options:
1. **Keep as-is:** Gender Harmony is an HL7 standard; the IG correctly references it
2. **Make optional:** Explicitly note Gender Identity as optional/jurisdiction-dependent
3. **Remove reference:** Remove the Gender Identity row from datamodel.md table
4. **Add jurisdiction note:** Add a note that Gender Identity support varies by jurisdiction and policy

## Affected Files
- `input/pagecontent/datamodel.md` — Line 13, Gender Identity reference in table 4.1

## Implementation Notes
- **Sensitive topic** — requires workgroup consensus, not a unilateral edit
- Gender Harmony project is an approved HL7 standard (cross-paradigm)
- FEHRM's negative vote is based on a specific US executive order (EO 14168)
- This is a UV realm IG — US-specific executive orders don't automatically apply
- However, the negative vote must be formally addressed
- Recommended approach: present options at workgroup and vote
- The reference in datamodel.md is a single cell in a table — the change is small but the decision is consequential
