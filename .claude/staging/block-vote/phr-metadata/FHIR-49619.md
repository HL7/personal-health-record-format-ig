# FHIR-49619: Digital documents for Continuity of Care and IPS should reference document Bundles and DocumentReference

**JIRA:** https://jira.hl7.org/browse/FHIR-49619
**Status:** Triaged | **Resolution:** None
**Ballot:** jan-2025
**Proposed Resolution:** Deferred (Blocked - Research Ongoing)

## Ballot Comment
Digital documents for CCD and IPS should reference document Bundles and DocumentReference rather than Composition. The current guidance conflates the Composition resource (clinical content) with the document paradigm (Bundle + DocumentReference for retrieval).

## Proposed Action
When research is complete:
1. Update `recordkeeping.md` to distinguish between Composition (clinical document content) and DocumentReference (document metadata/retrieval)
2. Update `datamodel.md` to clarify document Bundle usage for CCD/IPS
3. Add guidance on the FHIR document paradigm: Bundle type=document wrapping a Composition

## Affected Files
- `input/pagecontent/recordkeeping.md` — Add document paradigm guidance
- `input/pagecontent/datamodel.md` — Clarify document vs. composition

## Implementation Notes
- **Blocked:** Research ongoing on the correct approach
- Related to FHIR-53583 (DocumentManifest removal) — same domain
- The FHIR document paradigm: Bundle(type=document) → Composition → referenced resources
- DocumentReference provides metadata about the document for retrieval
- IPS uses Bundle(type=document) with IPS Composition — this should be referenced
- May need input from IPA/IPS workgroups
