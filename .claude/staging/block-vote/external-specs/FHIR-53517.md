# FHIR-53517: IPS harmonization

**JIRA:** https://jira.hl7.org/browse/FHIR-53517
**Status:** Submitted | **Resolution:** None
**Source:** PHR Council meeting
**Proposed Resolution:** Persuasive

## Ballot Comment
Harmonize PHR IG with International Patient Summary (IPS). The PHR should be able to generate and consume IPS documents.

## Proposed Action
Add IPS harmonization section to `api.md` describing:
1. How a PHR can generate an IPS document from its contents
2. How a PHR can import an IPS document
3. Mapping between PHR data model and IPS required sections
4. Reference to the IPS IG (already a dependency in sushi-config.yaml)

## Affected Files
- `input/pagecontent/api.md` — Add IPS harmonization section
- Preview exists at `phr-council-misc-preview` branch

## Implementation Notes
- IPS is already a dependency: `hl7.fhir.uv.ips: 1.1.0` in sushi-config.yaml
- Preview branch: `build.fhir.org/.../branches/phr-council-misc-preview/en/api.html`
- IPS sections map to PHR data model: Patient, Conditions, Medications, Allergies, etc.
- This aligns with the internationalization effort (Block A tickets)
- IPS $summary operation could be referenced as an API pattern
