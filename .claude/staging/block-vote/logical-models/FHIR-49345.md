# FHIR-49345: Support Device Identification when Observations are recorded by device or app

**JIRA:** https://jira.hl7.org/browse/FHIR-49345
**Status:** Triaged | **Resolution:** None
**Ballot:** jan-2025
**Proposed Resolution:** Deferred (Blocked on LOINC)

## Ballot Comment
If observations are recorded by a device or app, the device should be Must Support with identifiers. The PHR subgroup agreed: `Observation.device` should be Must Support but not required (not 1..1).

## Proposed Action
When LOINC terminology codes are available:
1. Update PGHD Observation profiles to add `Observation.device` as Must Support
2. Add device identification guidance to the PGHD profiles documentation
3. Ensure Device profile supports UDI (Unique Device Identifier) and app identification

## Affected Files
- `input/fsh/pghd/profiles/Observation-*.fsh` — Add device MS flag
- `input/fsh/pghd/profiles/Device.fsh` — Ensure proper identifier support

## Implementation Notes
- **Blocked:** Waiting on LOINC for terminology codes
- PHR subgroup consensus: MS but not 1..1 (device is optional but should be supported)
