# FHIR-49258: Structures: Logical Models - How they are connected to the IG?

**JIRA:** https://jira.hl7.org/browse/FHIR-49258
**Status:** Triaged | **Resolution:** None
**Ballot:** jan-2025
**Proposed Resolution:** Persuasive with Modification

## Ballot Comment
How are logical models connected to the IG? Many profiles appear to come from Apple HealthKit — the relationship should be clearly stated. The connection between the logical models, the profiles, and the IG's purpose is not documented.

## Proposed Action
1. If logical models are kept (see FHIR-50765): Add a narrative section explaining their purpose and relationship to the IG. Document the Apple HealthKit mapping explicitly.
2. If logical models are removed (per FHIR-50765): This ticket is automatically resolved — the confusing models are gone.
3. Either way: Ensure the PGHD profiles (which do map HealthKit concepts to FHIR) have clear documentation of their origin and purpose.

## Affected Files
- `input/fsh/models/` — Add or update narrative documentation
- Potentially `input/pagecontent/datamodel.md` or a new documentation section

## Implementation Notes
- The PGHD (Patient-Generated Health Data) profiles in `input/fsh/pghd/` are extensive (195 files)
- These map Apple HealthKit data types to FHIR Observations
- The logical models in `input/fsh/models/` are separate from PGHD profiles
- Depends on FHIR-50765 decision (keep vs. remove logical models)
- If keeping, a "Logical Models" section in the IG documentation should explain their purpose
