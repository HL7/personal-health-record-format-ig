# FHIR-50766: Remove Profiles for resources with no differential

**JIRA:** https://jira.hl7.org/browse/FHIR-50766
**Status:** Triaged | **Resolution:** None
**Ballot:** may-2025 | **Section:** 24.13
**Proposed Resolution:** Persuasive

## Ballot Comment
Numerous profiles for resources have no difference from the base resource. This is redundant and confusing. Examples: PHR Patient, PHR Provenance. Recommend removing all profiles that do not have a differential, unless there is a logical reason to keep them.

## Proposed Action
1. Audit all 24 profiles in `input/fsh/profiles/functional-model/` for differentials
2. For each profile, check if it adds any constraints (MS flags, cardinality, bindings, extensions)
3. Remove profiles that are pass-through (no constraints beyond base resource)
4. Update any references to removed profiles in documentation

## Affected Files
- `input/fsh/profiles/functional-model/*.fsh` — Remove empty profiles
- `input/pagecontent/datamodel.md` — Update references if profiles are removed
- `sushi-config.yaml` — Remove profile entries if needed
