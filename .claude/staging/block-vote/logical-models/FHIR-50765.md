# FHIR-50765: Experimental Logical Models

**JIRA:** https://jira.hl7.org/browse/FHIR-50765
**Status:** Triaged | **Resolution:** None
**Ballot:** may-2025
**Proposed Resolution:** Persuasive with Modification

## Ballot Comment
Three experimental logical models are published — why? Net new FHIR resources should go through FHIR Infrastructure (FHIR-I). Suggest removing them.

## Proposed Action
Review the 2 logical models (CDS.fsh, PatientDataReceipt.fsh) and decide:
1. **Option A (Remove):** Delete the experimental logical models. They represent concepts not yet mature enough for a ballot specification.
2. **Option B (Promote):** Convert from "experimental" to "trial-use" with proper constraints, clear documentation of purpose, and narrative explaining how they relate to the IG.

## Affected Files
- `input/fsh/models/CDS.fsh` — Review and potentially remove
- `input/fsh/models/PatientDataReceipt.fsh` — Review and potentially remove
- `input/fsh/models/PatientDataReceipt.fsh.bkup` — Clean up backup file regardless
- `sushi-config.yaml` — Update if removing

## Implementation Notes

- If removing, ensure no other profiles or examples reference these models
- Related to FHIR-49258 (Logical Models connection to IG) — if models are removed, FHIR-49258 is also resolved
