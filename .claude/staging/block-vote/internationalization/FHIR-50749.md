**Status:** Triaged | **Resolution:** None

**Block Vote:** Internationalization (Block A) — with FHIR-50394, FHIR-50632, FHIR-50740

## Ballot Comment
Table 4.1 has a column devoted to Argonaut R4 which is sparsely populated and not all readers will know what Argonaut is. If keeping the section as international, guides from other countries and at least IPS/IPA should be referenced. Argonaut should be defined or linked.

## Proposed Action
1. Add footnote or inline definition for "Argonaut" in `datamodel.md` table
2. Add IPS and IPA columns to Table 4.1 alongside Argonaut R4
3. Consider renaming "Argonaut R4" column to "US Realm (Argonaut R4)" for clarity
4. Add link to Argonaut project page

## Affected Files
- `input/pagecontent/datamodel.md` — Table 4.1 (lines 7-52)
