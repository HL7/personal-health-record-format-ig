# FHIR-50394: UV-realm profile very US-specific

**JIRA:** https://jira.hl7.org/browse/FHIR-50394
**Status:** Triaged | **Resolution:** None
**Ballot:** may-2025 | **Section:** 1.3, 3
**Proposed Resolution:** Persuasive with Modification
**Block Vote:** Internationalization (Block A) — with FHIR-50632, FHIR-50740, FHIR-50749

## Ballot Comment
Commenter notes the IG is "overall very useful and promising" but the regulatory scope is narrow for a UV realm IG. Requests at minimum adding the European Health Data Space (EHDS) Regulation. Also notes that Conformance Recommendations section needs international coordination.

## Proposed Action
1. Restructure `index.md` Section 1.3 "Relevant Law" from a US-only list to an international table with columns for jurisdiction (US, EU, Japan, etc.)
2. Add EHDS Regulation, GDPR, Japan PHR Business Association Act to the law table
3. Update `conformance.md` to include IPS and IPA references alongside US Core and Argonaut
4. Add note that national-realm companion IGs can extend this UV base

## Affected Files
- `input/pagecontent/index.md` — Restructure Section 1.3 "Relevant Law"
- `input/pagecontent/conformance.md` — Add IPS/IPA/EHDS references to conformance table
