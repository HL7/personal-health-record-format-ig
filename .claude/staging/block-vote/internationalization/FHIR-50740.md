# FHIR-50740: Universal realm FHIR IG yet only US law is referenced and based on US Core

**JIRA:** https://jira.hl7.org/browse/FHIR-50740
**Status:** Triaged | **Resolution:** None
**Ballot:** may-2025 | **Section:** 1.3, 1.7, 4.1
**Proposed Resolution:** Persuasive with Modification
**Block Vote:** Internationalization (Block A) — with FHIR-50394, FHIR-50632, FHIR-50749

## Ballot Comment
Only US-specific law citations and US-relevant references. The data model references US Core, C-CDA on FHIR, and Argonaut — all US-realm artifacts. Commenter suggests either adding international representation or making this a US Realm IG.

## Proposed Action
1. Keep as UV realm IG but add international references throughout
2. `index.md` Section 1.3: Add international laws (see FHIR-50632)
3. `index.md` Section 1.7 (References): Add IPS, IPA, EHDS references
4. `datamodel.md` Table 4.1: Add IPS column alongside Argonaut R4 column
5. `conformance.md`: Ensure IPS/IPA are prominently listed alongside US Core

## Affected Files
- `input/pagecontent/index.md` — Sections 1.3 and 1.7
- `input/pagecontent/datamodel.md` — Table 4.1 (add IPS column)
