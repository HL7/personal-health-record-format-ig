# FHIR-50737: Clarify the purpose of phr format

## Ballot Comment
Recommend changing language about .sphr format and conformance to clarify the IG specifies a communication format, not PHR implementation requirements. The Functional Model page should make clear that .sphr conformance is about the exchange format.

## Proposed Action
1. Update `functionality.md` lines 4-5: clarify that .sphr conformance means the exchange format uses FHIR data schemas, not that PHR systems must use FHIR internally
2. Update `datastorage.md` intro (line 5): reframe conformance statement to focus on import/export
3. Ensure consistent messaging with FHIR-50736 changes to `datamodel.md`
