# FHIR-50763: Use of word record confusing - recommend clarity

**JIRA:** https://jira.hl7.org/browse/FHIR-50763
**Status:** Triaged | **Resolution:** None
**Ballot:** may-2025 | **Section:** 7
**Proposed Resolution:** Persuasive

## Ballot Comment
Change "Once an encrypted Personal Health Record is generated..." to "Once an encrypted .phr or .sphr file is generated..." to avoid confusion between the record concept (the patient's health record) and the file format (.phr/.sphr).

## Proposed Action
Search for "encrypted Personal Health Record" in datastorage.md and recordkeeping.md, replace with "encrypted .phr or .sphr file" throughout. Also review other instances where "record" could mean the file vs. the concept.

## Affected Files
- `input/pagecontent/datastorage.md` — Replace ambiguous "record" references
- `input/pagecontent/recordkeeping.md` — Same search and replace

## Implementation Notes
- The word "record" is overloaded in this IG: it means both the patient's health record (concept) and the .phr/.sphr file (artifact)
- This is a terminology consistency fix — relatively straightforward
- May want to establish a convention: "PHR" = the concept, ".phr file" or ".sphr file" = the artifact
- Quick grep for "Personal Health Record" in both files to find all instances
