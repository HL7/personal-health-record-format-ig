# FHIR-49244: Make scope of the IG more clear. Guide the reader on how to read the IG.

**JIRA:** https://jira.hl7.org/browse/FHIR-49244
**Status:** Triaged | **Resolution:** None
**Ballot:** jan-2025
**Proposed Resolution:** Persuasive

## Ballot Comment
Reviewer identified 3 main contributions of the IG (file formats, APIs, longitudinal records) but this isn't clear to first-time readers. The IG should guide the reader on how to read it — what the main sections cover and in what order.

## Proposed Action
Add a "Reader's Guide" or "How to Use This IG" paragraph near the top of `index.md`, after the introduction:

> "This Implementation Guide provides three main contributions:
> 1. **File Formats** (.phr, .sphr) for portable personal health records (see [Record Keeping](recordkeeping.html))
> 2. **API Patterns** for importing and exporting health records (see [API Endpoints](api.html))
> 3. **Data Model** mapping PHR-S Functional Model requirements to FHIR resources (see [Data Model](datamodel.html))"

## Affected Files
- `input/pagecontent/index.md` — Add reader's guide paragraph (after line ~4)
