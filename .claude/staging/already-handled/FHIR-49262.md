# FHIR-49262: Relevance of Operating Systems page

**JIRA:** https://jira.hl7.org/browse/FHIR-49262
**Status:** Triaged | **Resolution:** None
**Ballot:** jan-2025
**Tracker Status:** [W] Won't Fix
**Proposed JIRA Resolution:** Not Persuasive

## Rationale for Not Persuasive
Per editor (Hisashi) — the Operating Systems page provides practical implementation guidance for file type associations on macOS, iOS, and JavaScript/Node.js. While not typical for a FHIR IG, the PHR file format (.phr/.sphr) requires OS-level file association to be usable. The page is maintained and provides implementer value.

## Workgroup Action Needed
Vote Not Persuasive — page retained per editorial decision.
